# Фантомный грид (Phantom Grid)

## Как воспроизвести

1. Взять локальный чертеж (`bp.sbc`)
2. Десериализовать через `MyObjectBuilderSerializerKeen.DeserializeXML`
3. Извлечь `MyObjectBuilder_CubeGrid[]`
4. Сделать `MyAPIGateway.Entities.RemapObjectBuilderCollection()`
5. Вызвать `MyAPIGateway.Entities.CreateFromObjectBuilderAndAdd()`

## Симптомы

Грид **визуально появляется** в мире на нужных координатах, но:

- Клик по блоку — не загорается синяя рамка
- Нельзя удалить/починить/настроить
- Нет коллизии — сквозь грид проходит персонаж/корабли
- Не отображается в списке гридов (Entity List / Info Screen)
- Нет физики — висит в воздухе и не падает даже при выключенных дамперах
- Может исчезнуть при перезаходе в мир (не сохранён)

## Почему так происходит

### `CreateFromObjectBuilderAndAdd` делает не всё

Этот метод создаёт `MyEntity` из ObjectBuilder'а и добавляет в `MyEntities`, но
**не инициализирует** сетевую/физическую/визуальную подсистемы грида до конца:

```
CreateFromObjectBuilderAndAdd(gridBuilder)
  ├─ Создаёт MyCubeGrid
  ├─ Вызывает MyCubeGrid.Init(gridBuilder)
  │    ├─ Грузит блоки (CubeBlocks) из ObjectBuilder
  │    ├─ Создаёт кубы в сетке (SetBlock)
  │    └─ Но не вызывает Init() для каждого блока!
  ├─ Добавляет в MyEntities (AddEntity)
  │    └─ Визуализация появляется — грид видно
  └─ ??? Активация физики, сетевой синхронизации — нет
```

### Что пропущено

| Система | Метод | Вызван? |
|---------|-------|---------|
| Визуализация блоков | `MyCubeGrid.Init(ob)` | ✅ |
| Добавление в мир | `MyEntities.AddEntity()` | ✅ |
| Физика блоков (Havok) | `MyCubeBlock.Init()` → `CubeBlock.Init()` | ❌ |
| Сетевая регистрация | `MyMultiplayer.ReplicateEntity()` | ❌ |
| Обновление соседей | `MyCubeGrid.UpdateBlockNeighbours()` | ❌ |
| Терминальная система | `MyGridTerminalSystem.Init()` | ❌ |
| Группы (коннекторы) | `MyGridGroups.OnGridAdded()` | ❌ |
| Газ/кислород | `MyGridGasSystem.Init()` | ❌ |
| Сохранение в сейв | `MySession.Save()` — грида нет в списке | ❌ |

### Правильный спавн — как делает игра

Когда игрок спавнит чертеж через **проектор** (`MyProjectorBase.Build()`)
или через **F10 → Blueprint → Spawn**, игра использует другой путь:

1. `MyPrefabManager.SpawnPrefab()` / `AddShipPrefab()`
2. Внутри вызывает `MyEntities.CreateFromObjectBuilderAndAdd()`
3. **Плюс** запускает `MyEntities.RaiseEntityCreated` и внутренние события
4. **Плюс** выполняет `Init()` для каждого блока грида
5. **Плюс** регистрирует грид в `MySession` для сохранения

### Ключевое различие

```
Игра (F10/проектор):              Мы (CreateFromObjectBuilderAndAdd):
  Init блока ✓                      Init блока ✗
  Physics body ✓                    Physics body ✗
  Register in session ✓             Register in session ✗
  Network sync ✓                    Network sync ✗
```

## Как исправить

Вызвать недостающие инициализации после `CreateFromObjectBuilderAndAdd`:

```csharp
var grid = MyAPIGateway.Entities.CreateFromObjectBuilderAndAdd(gridBuilder) as MyCubeGrid;
if (grid == null) return;

// 1. Инициализировать каждый блок
foreach (var block in grid.GetBlocks())
{
    if (block.FatBlock is MyCubeBlock fatBlock)
        fatBlock.Init(block.FatBlock.ObjectBuilder); // нужно сохранить ObjectBuilder!
}

// 2. Создать физику
grid.Physics?.Enabled = true;

// 3. Зарегистрировать в сессии для сохранения
MySession.Static?.RegisterEntity(grid);

// 4. Обновить сетку коннекторов/групп
MyAPIGateway.GridGroups?.OnGridAdded(grid);

// 5. Оповестить терминальную систему
grid.RaiseGridChanged();
```

**Проблема**: у блоков, созданных из ObjectBuilder'а внутри `CreateFromObjectBuilderAndAdd`,
исходный ObjectBuilder не сохраняется — метод `block.GetObjectBuilder()` может вернуть
`null` или некорректный OB, потому что клининг OB происходит сразу после создания.

## Вывод

`CreateFromObjectBuilderAndAdd` даёт **визуальное представление** грида, но
**неполноценную игровую сущность**. Это побочный эффект, который может быть
полезен для:
- Предпросмотра гридов (без затрат на физику)
- Маркеров/маяков
- Визуальных демонстраций

Для полноценного спавна нужно либо:
- Использовать `MyPrefabManager.SpawnPrefab()` (работает только с префабами из SBC)
- Либо вручную вызывать цепочку `Init → Physics → Register → GridGroups → Save`

## Альтернатива: префабы вместо чертежей

Если положить чертеж как `.sbc` в `Content/Data/Prefabs/`, его можно грузить
через `MyAPIGateway.PrefabManager.SpawnPrefab()` — это **полноценный** спавн.
Но требует модификации игровых файлов.

## Релевантные классы

| Класс | Метод |
|-------|-------|
| `MyPrefabManager` | `SpawnPrefab()`, `AddShipPrefab()`, `CreateGridsFromPrefab()` |
| `MyProjectorBase` | `Build()` — строит грид из проекции |
| `MyCubeGrid` | `Init()`, `OnBlockAdded()`, `RaiseGridChanged()` |
| `MyCubeBlock` | `Init(MyObjectBuilder_CubeBlock)` |
| `MyGridGroups` | `OnGridAdded()`, `OnGridRemoved()` |
| `MySession` | `RegisterEntity()`, `UnregisterEntity()` |
